# Response-Letter Voice Guide

Condensed and generalized from Aperivue/medsci-skills `skills/revise/references/r2r_voice.md` (MIT). Read it before drafting a response-to-reviewers letter or a revision cover letter. All examples are synthetic.

---

## The core rule

State **what changed and why** in plain prose. Quote the new sentence and name the section. Say nothing about **how** you found or made the edit.

Machine-drafted letters narrate the editing mechanism: which line changed, how many phrases were swapped, what a search returned. Reviewers read this as checklist-clearing. Describing a **new analysis or fieldwork the authors did** is science and welcome. Describing the text-editing operation is not.

## Acceptable formats

All of these read as human. Pick one and keep it consistent:

- **Free prose:** "We agree. We have added to the Methods: '…'."
- **Structured:** `Response:` paragraph + `Changes in the manuscript:` block, optionally with `Original: '…'` → `Revised: '…'`.
- **Two-column table:** comment | response.

## Banned (AI-tells)

| Don't write | Write instead |
|---|---|
| "v2 adds one sentence at line 88" | "We have added to the Study area section: '…'" |
| "softened six over-interpretive phrases" | "We have rephrased these passages so that …", plus one before/after example |
| "a search confirmed zero occurrences" | (delete; describe the corrected wording) |
| "No further manuscript change." | "This is addressed in the Discussion: '[existing sentence]'." |
| "(Methods §2.3)", any `§` | "in the Methods (Data collection subsection)" |
| internal working-file line numbers | section name, or revised-manuscript page/line stated once as such |
| "Reviewers 1 and 3 found this appropriate" | answer this reviewer on the merits |
| "We confirm this statement was not weakened" | point to where it is handled and stop |
| a paragraph of gratitude to a satisfied reviewer | "Thank you." |
| the same opener on every response | vary by stance (see below) |

## Vary openers by stance

- "We agree, and have revised accordingly."
- "This is a fair point about the spatial scope of the inventory."
- "We see how the original wording invited this reading; we have corrected it."
- "The reviewer is correct. We found an error in … and have corrected it."
- "We respectfully maintain the original classification, for the reasons below."

## Three response skeletons

**A. Full agreement (most common):**
> [reviewer comment]

"We agree. We have [substantive change] in the [section]. The revised text reads: '[new sentence verbatim].'" Use 2–5 sentences.

**B. Partial agreement:** "The reviewer raises a valid point about [aspect]. We have [the accepted part] in the [section]. We have not [the declined part] because [specific reason]; instead we [the bounded alternative], which addresses the underlying concern."

**C. Evidence-backed rebuttal (author-approved only):** "We understand the concern that [restate fairly]. We respectfully maintain [position] because [reasoning from data/design/literature, cited]. To make this clearer to readers, we have added to the [section]: '[new sentence].'" Never write "the reviewer is wrong."

**Graceful defer:** "We considered [request], but believe [change made] addresses the underlying concern without [cost]. If the reviewer prefers, we are happy to add [item] in a further revision."

## Location pointers

- Point by **section name** first.
- Revised-manuscript page/line numbers are fine **only** if they match the file the reviewer will read. Say once at the top: "All page and line numbers refer to the revised manuscript." Otherwise use section names only.
- Quote the new text when the change is a sentence or two. Summarize larger changes in one sentence plus the section.

## Splitting and disclosure

- Split a multi-point reviewer paragraph into separate comments (R1-3a, R1-3b …), each with its own quote and response.
- Fold any methodological disclosure (a limitation, a deviation) into the response to the comment that raised it. Never put it in a separate front section, and never drop it.

## Length

| Item | Guide |
|---|---|
| MINOR response | 50–150 words |
| MAJOR response | 150–400 words |
| REBUTTAL response | 200–500 words |
| Cover letter (R1) | 200–400 words |
| R2+ satisfied reviewer | 1–2 sentences |

Headroom under a journal word cap is not a target. Do not pad.

## Pre-send checklist

- [ ] Zero `§`
- [ ] No working-file line numbers, version prefixes, or tooling words
- [ ] No bare "no change" stubs
- [ ] Openers varied
- [ ] New text quoted verbatim where a sentence changed
- [ ] Multi-point comments split
- [ ] Satisfied reviewers answered briefly
